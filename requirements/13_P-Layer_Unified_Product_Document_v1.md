### 0.1 理论参考书目与使用层级

以下资料是 P-Layer 研究训练逻辑的默认参考，不是可以替代用户判断的“自动答案来源”。当产品流程、科学环、研究问题形成或证据解释需要理论依据时，按以下层级使用：

1. **首要理论参考书目**：《The Practice of Social Research》；用于研究逻辑、经验与理论的关系、研究设计、证据判断和社会科学研究的基本规范。
2. **第二理论参考书目**：《社会研究方法》（第六版，风笑天）；用于研究流程、研究问题、概念与变量、假设、研究设计、资料收集和资料分析的教学化表达。
3. **科学环结构参考**：《社会学研究方法》；重点参考华莱士科学环的两个主要入口，并将其转译为 P-Layer 的 O 观察入口与 T 理论/文献入口。

## 1. 一句话产品定义

> P-Layer 是一个以 Wallace 科学环为认知导航、以用户自己的 Idea 为核心、以 Pia! 为可选教练，帮助早期研究者从好奇出发，发展理论、预测、证据和经验概括的个人科研训练系统。

## 2. 产品使命与问题意识

P-Layer 尝试降低进入科研和持续做研究所需的非必要资源门槛，让缺少导师、实验室、RA 机会或学术关系的人，也能逐步获得：

- 理解研究如何开始的能力；
- 判断一个想法如何变得更清楚的能力；
- 从命题走向预测和证据的工具；
- 管理 Idea、理论、文献和项目历史的空间；
- 形成可保存、可分享、可继续发展的研究轨迹。

P-Layer 不替代大学、导师或正式学术共同体，不承诺录取、发表、职位或资金结果，也不把复杂研究伪装成一个自动生成答案的按钮。

## 3. 核心用户价值

用户可以从以下任意起点开始：

- 生活观察；
- 模糊疑问或直觉；
- 文献批判或阅读困惑；
- 商业实践发现；
- 实验异常或已有数据；
- 已经暂停的旧 Idea。

用户不必一次完成一篇论文，也不必完成完整科学环。软件的价值是让每一步都能留下可回看的成果，并允许用户以后继续、修正、分支或归档。

核心价值链：

```text
好奇/观察
→ 形成更清楚的判断
→ 发展理论与概念
→ 形成预测和 Research Question
→ 连接文献与证据
→ 产生阶段性成果
→ 接收反馈并重新检查
→ 形成新版本或新 Idea
```

## 4. 产品对象模型

```text
User
└── Idea
    ├── 原始观察与头脑风暴成果
    ├── 理论轨道记录
    ├── 实证轨道记录
    ├── RQ 分支
    │   └── RQ 版本
    ├── 文献连接
    ├── PDF 成果版本
    │   └── 外部反馈与反馈反思
    └── 生命周期与完整版本历史

Research Project
└── 由用户选择从某个 RQ 转入
    ├── 研究执行步骤
    ├── Study
    └── 后续数据版本与分析结果
```

基本关系：

- 一个 Idea 可以分支出多个 RQ；
- 理论 RQ 与实证 RQ 可以属于同一个 Idea，也不要求相同；
- 一个 RQ 可以进入正式研究项目，但不会自动关闭同一 Idea 下的其他 RQ；
- 一个 Idea 可以连接多篇文献，一篇文献也可以连接多个 Idea；
- 所有用户确认后的内容都必须能够保存、修改、删除、暂停和回看；
- 旧版本、旧 PDF 和旧反馈不能被新版本悄悄覆盖。

## 5. 顶部导航与区域边界

正式导航采用五个入口：

```text
主页｜科学环｜研究项目｜看板｜设置
```

### 5.1 主页：我的研究空间

回答：

> 我最近在做什么？我可以继续什么？

主页负责：

- 登录/进入时的名言或 Pia! 鼓励语；
- 最近打开的真实 Idea；
- 最近连接的真实文献；
- 待处理的真实反馈；
- 最近生成的真实 PDF；
- 用户主动创建 Idea 或继续探索的入口。

空白用户主页不显示任何示例 Idea、示例项目、示例 Deadline 或示例研究结果。

主页的工作版纵向层级固定为：

```text
实际 P-Layer Logo
→ 名言/鼓励语
→ 捕捉 Idea、管理研究资产、继续项目
→ 用户真实的最近安排 / Deadline / 工作
```

如果用户没有真实内容，最近安排区域显示清晰的空状态或不显示，不得用演示数据填充。

### 5.2 科学环：我的研究思考入口

回答：

> 一个研究想法如何在观察、理论、预测和证据之间发展？

科学环内部提供：

- 输入一个新 Idea；
- 继续已有 Idea；
- 头脑风暴；
- 研究连接/文献网络；
- 重新检查假设；
- 形成 RQ；
- 生成阶段性 PDF；
- 用户主动进入正式研究项目。

Idea、理论和文献的管理属于科学环内部的“研究资产库”，不是顶部独立研究阶段。

### 5.3 研究项目：我的正式研究

只管理已经由用户选择成立或准备成立的正式 Research Project。它不承担最初的模糊 Idea，也不把用户自动推进为项目。

### 5.4 看板：我的研究行动

看板只管理行动和任务，例如阅读、访谈、实验准备、数据准备、分析、反馈处理和复盘。看板不替代 Idea 库、文献网络或科学环。

### 5.5 设置：我的 P-Layer 环境

设置负责账户、个人资料、Pia! 偏好、本地模型、数据位置、导入导出、隐私、删除和关于 P-Layer。

## 6. 工作版与宣传版

P-Layer 必须区分两种体验：

### 6.1 工作版

工作版面对已经进入个人工作空间的用户。首屏应该安静、克制、可持续使用：

```text
P Logo
→ 一条名言/鼓励语
→ 用户真实的继续工作入口
→ 用户真实的最近工作
```

工作版不显示宣传性主标题、不显示“A Research Workspace”营销定位、不显示虚构内容，也不把主页做成产品介绍页。

P Logo 是工作版的轻交互入口：用户点击 P 后，P 轻微抖动并短暂模糊，随后更新名言。名言右下角不放额外刷新按钮。

名言内容必须保存作者、来源状态和出处信息。来源未核实的内容不得用确定性引号和确定署名伪装成可靠原文。

### 6.2 宣传版

宣传版是未来面向未注册用户的官网首页，用于解释产品使命、科学环和使用价值。宣传版不得与个人工作版混用，也不得把宣传内容写入用户研究记录。

当前个人版 v1 优先完成工作版，不优先开发宣传版。

## 7. Wallace 科学环

### 7.1 认知模型

Wallace 科学环用于表达理论与经验之间的往返，而不是固定的线性任务清单：

```text
理论 → 假设/预测 → 观察与证据 → 经验概括 → 理论修正
```

P-Layer 界面采用用户确认的四卡展示顺序：

```text
O 经验观察 → E 经验概括 → T 理论与概念 → H 命题与假设 → 回到 O
```

这只是界面上的循环阅读顺序；它不把科学研究规定为只能从 O 开始，也不把四个节点变成必须逐项完成的关卡。

### 7.2 两个主要入口

对于新 Idea，科学环有两个主要认知入口：

1. **O 观察入口**：从生活现象、疑问、商业发现、实验异常或数据开始；
2. **T 理论/文献入口**：从理论、概念、文献批判或已有争论开始。

这是新研究的主要入口分类，不限制已有 Idea 在之后访问任何节点。已有 Idea 可以从任意节点进入。

### 7.3 四个固定节点

| 节点 | 核心问题 | 用户成果 |
|---|---|---|
| O 经验观察 | 我看见了什么？证据如何获得？ | 观察、对象、范围、证据方向 |
| E 经验概括 | 证据显示了什么规律？ | 描述结果、经验模式、例外与限制 |
| T 理论与概念 | 我如何理解这个现象？ | 概念、理论依据、文献批判、命题 |
| H 命题与假设 | 如果这个解释成立，会出现什么？ | 逻辑推演、假设、预测、RQ、替代解释 |

### 7.4 交互规则

- 只显示四张循环卡片；
- 点击任意节点，沿最短方向旋转并聚焦；
- 当前节点高亮，邻居保留上下文；
- “旋转聚焦”和“进入工作空间”分成两个短阶段；
- 进入后仍属于同一个 Idea；
- 至少完成当前方向上的局部推理后，用户可以保存并离开；
- 用户可以回退、暂停、归档、重新开始或选择另一个节点；
- 科学环显示当前 Idea 已经走过的节点和当前节点；
- 动画不能改变 Idea、RQ、项目或数据状态；
- 理论轨道与实证轨道是相互连接的关系，不是上下级关系；
- 用户只探索一条轨道时，不制造另一条轨道的“未完成压力”；
- 只有用户主动进入另一条轨道后，才显示双轨进度。

科学环中心的主要动作是：

```text
输入我的 Idea
```

已有 Idea 的列表和继续入口属于次级入口，不取代“输入我的 Idea”。

### 7.5 科学环的实际界面形态

科学环不是从 Z 轴观察的卡片堆叠，而是从 X 轴观察的水平循环轮播。它表达的是同一组认知节点可以不断换位、回看和重新进入，而不是把节点压在彼此后面。

固定显示四个节点：

```text
O → E → T → H → O → E → …
```

界面规则：

- 只保留四种卡片内容，不增加第五个科学环节点；
- 每次以一个当前节点为视觉焦点，当前节点高亮并显示完整内容；
- 当前卡片左右都显示相邻卡片的可见部分，邻居不被完全遮挡；
- 邻居卡片采用扁长卡片形态，规划尺寸与看板主要卡片体系一致；
- 两侧邻居相对当前卡片缩小，并叠加轻微灰色遮罩，表示上下文而非当前工作焦点；
- 邻居露出比例允许在 50% 与 75% 两档之间调整，默认优先保证左右两侧都能识别节点字母和标题；
- 循环必须是连续的：当当前节点为 H 时，右侧应能进入 O；当当前节点为 O 时，左侧应能进入 H；
- 卡片移动沿水平方向完成，禁止使用会造成上下堆叠误解的 Z 轴遮挡、强透视或 3D 旋转；
- 点击、左右箭头或水平拖动均只改变当前焦点，不直接修改 Idea、RQ、项目或数据；
- 旋转完成后，当前节点始终保持明确的高亮和选中状态；
- 用户可以从当前节点进入对应工作区，也可以只旋转浏览而不进入；
- 在窄屏上优先保证当前卡片完整、左右邻居至少保留节点字母和标题，不为了露出邻居而压缩核心内容。

因此，科学环的最小交互模型是：

```text
水平拖动 / 点击相邻卡片
→ 四卡连续换位
→ 当前卡片高亮
→ 用户决定进入、继续、保存或离开
```

## 8. 头脑风暴：科学环前置孵化层

头脑风暴不是普通笔记，也不是自动生成 RQ 的机器，而是从好奇心进入科学推理的训练。

建议路径：

```text
原始观察/想法
→ 初步命题
→ 可能解释
→ 预测
→ 前提与边界
→ 替代解释
→ 证据方向
→ 初步 Research Question
```

每一步都保存用户自己的成果，包括错误、误解、被放弃的解释和未解决问题。早期 Idea 不因不成熟而被阻止保存。

Pia! 默认不主动盘问。只有用户主动求助、卡住或出现严重逻辑错误时，Pia! 才提供解释、示范、反例或澄清。Pia! 的建议写入正式记录前必须由用户确认。

头脑风暴可以在任意阶段暂停。用户不必生成 PDF、不必进入项目，也不必完成完整科学环。

## 9. 研究资产库

研究资产库至少包含三个类型：Idea、理论、文献。

### 9.1 Idea

Idea 可以是任何对用户有价值的好奇，不要求一开始具备学术价值、逻辑完整性或可立即研究性。

分类只描述进入语境，不评价质量：

- 学术理论；
- 文献阅读；
- 商业实践；
- 生活观察；
- 实验/数据。

成熟度与生命周期必须分开：

| 等级 | 名称 | 最小成果 |
|---|---|---|
| I0 | 种子 | 原始 Idea |
| I1 | 澄清 | 现象与个人动机 |
| I2 | 命题 | 初步命题、前提和边界 |
| I3 | 可预测 | 可检验预测与替代解释 |
| I4 | 有依据 | 文献、数据或证据线索 |
| I5 | 初步 RQ | 范围清楚的 Research Question |
| I6 | 可立项 | RQ、概念、证据路径和下一步足够清楚 |

成熟度用文字、字母和颜色共同表达，不使用单一分数。等级可以跨越、下降和回退，系统记录变化原因。

生命周期为：

```text
Active 进行中
→ Paused 暂停
→ Archived 归档 / Abandoned 放弃
→ Converted 转为研究项目
```

放弃不是失败，归档不是删除，暂停不意味着必须继续。

### 9.2 理论

理论库保存用户已经知道、正在理解或希望重新使用的：

- 概念；
- 理论机制；
- 命题；
- 理论适用边界；
- 支持或质疑理论的文献；
- 理论如何改变某个 Idea。

### 9.3 文献与研究连接

文献网络不是科学环的第五个节点，而是横向连接层。

支持：

- Idea ↔ 文献多对多关系；
- 文献 ↔ 文献的相似、引用或主题关系；
- 文献连接到 Idea、命题、预测或 RQ；
- 关系类型：支持、质疑、启发、反驳、提供理论、提供测量、提供方法、限定边界、改变我的想法；
- 区分用户确认、Pia! 建议和系统推断；
- 记录“为什么有关”；
- 不因网络距离、连线粗细或相似度自动宣称因果、质量或理论影响。

## 10. RQ、版本与阶段性成果

一个 Idea 可以有多个研究问题：

```text
Idea-10
├── Idea-10 / RQ-1 理论研究问题
└── Idea-10 / RQ-2 实证研究问题
```

版本支持分层编号：

```text
Idea-10 / V5 / RQ-2 / V3
```

用户修改命题、假设或 RQ 后，可以主动形成新版本。旧版本必须可查看、比较和恢复。RQ 进入正式项目后，不自动关闭同一 Idea 下的其他 RQ。

用户在任意阶段都可以生成阶段性 PDF，但不必生成。PDF 可以是：

- Idea 简报；
- 理论研究构想；
- 实证研究构想；
- 综合研究构想；
- RQ 成果简报。

PDF 只展示用户确认后的研究成果，不展示 Pia! 对话、AI 建议、成熟度判断、私密错误记录或 AI 生成痕迹。

## 11. 反馈与反思

反馈绑定具体 PDF 版本，而不是直接覆盖 Idea。

反馈支持：

- 类型：表达不清、逻辑问题、理论建议、文献建议、研究价值、其他；
- 自由文字；
- 姓名/昵称或匿名；
- 未阅读、正在考虑、已采纳、暂不采纳、已转为新 Idea；
- 用户决定是否采纳；
- 用户可以将反馈归档为原 Idea 修改，或主动转为新 Idea；
- 反馈状态变化保留历史；
- Pia! 可以整理反馈，但不能替用户裁决或自动修改；
- 原始反馈必须保留，摘要不能替代原文。

## 12. 正式研究项目与后续数据阶段

当用户认为某个 RQ 已经具备项目起点时，用户主动将其导入正式研究项目。系统只提供资格提示，不自动升级。

正式研究项目保留九步执行结构：

```text
研究问题
→ 理论与研究假设
→ 变量定义与操作化
→ 研究设计与功效分析
→ 预注册、伦理与数据收集计划
→ 平台招募与问卷/实验执行
→ 数据冻结、清理与质量审计
→ 统计分析与结果解释
→ 回到假设：支持、部分支持、未获得支持或证据不足
```

个人版 v1 的重点是前置研究形成，不要求立即实现：

- 真实实验平台；
- 真实数据收集；
- 完整统计引擎；
- 自动邮箱读取；
- 团队协作。

但数据结构必须为未来的 Study、数据版本、分析记录、效应量、置信区间、偏离记录和假设结论预留接口。

## 13. Pia! 的产品边界

Pia! 是教练，不是研究者，不是管理者，也不是代笔者。

Pia! 可以：

- 澄清概念；
- 提供研究方法解释；
- 帮助识别逻辑问题；
- 提供反例和替代解释；
- 比较文献；
- 整理反馈；
- 解释数据能够和不能够说明什么。

Pia! 不可以：

- 替用户决定研究价值；
- 自动生成并固化用户的假设或 RQ；
- 把用户观察直接写成因果结论；
- 强迫用户完成流程；
- 未经确认修改正式研究记录；
- 删除用户的错误、旧版本、反馈或未解决问题。

## 14. 工作版视觉与交互原则

工作版使用长期、克制、可持续的视觉暗示：

- 苹果系统字体优先；
- 顶部只保留主导航，不放 P-Layer 品牌锁定区、Research Workspace 副标题或宣传性 Hero；
- 主导航在顶部容器内水平、垂直居中；
- 工作版页面中的 P-Layer Logo 使用实际 Logo 资源，不用单独的大写字母 P 代替；
- 主页首屏的 Logo、名言和主要工作入口在可用视口内保持水平与垂直视觉居中，并考虑顶部导航所占空间；
- 名言作为首屏主要视觉内容：字号明显放大，使用完整引号和作者信息；
- 名言卡片保持足够留白，并与下方三个主要入口形成明确的上下层级，不重叠；
- 三个主要入口固定为“捕捉一个 Idea”“管理研究资产”“继续一个项目”，等宽、同层级、可直接进入对应功能；
- 最近安排位于三个主要入口之后，只显示用户真实创建的 Deadline、任务或最近工作；
- 页脚只承担次要信息，字号和视觉权重小于主体内容；关于 P-Layer 的品牌叙事和“让每一份好奇，都有继续工作的地方”等宣传文字放入“设置 → 关于我们”，不放在工作版主页；
- 不用演示数据制造“已经有研究”的假象；
- 可控主干使用更明确的字号、位置、对比度和结构；
- 可调整内容使用较轻的颜色、次级文字和可编辑状态；
- 科学环使用四张固定卡循环展示，不做游戏化积分或排行榜；
- 交互提示只在真实需要时出现；
- “向下滑动查看更多”只在当前页面确实超出视口且用户位于页面顶部时显示；它是浮动提示，水平居中，位于名言卡片与三个入口卡片之间，并与上下两组保持相等的视觉距离；用户开始下滑后隐藏，不能与任一卡片重合；
- 空状态只解释如何开始，不填充虚假的样本内容。

主页 UI 的核心原则是：先让用户看到“我现在可以开始什么”，再让用户看到“我过去做过什么”。任何宣传语、样例项目、样例数据或过强的视觉装饰，都不能抢占真实研究入口。

## 17. v1 验收标准

一个没有科研训练的用户应能：

1. 从一个模糊想法开始；
2. 保存原始 Idea；
3. 在头脑风暴中形成观察、命题、解释、预测、边界、替代解释和证据方向；
4. 从 O 或 T 进入科学环，并能从任意节点继续；
5. 形成至少一个初步 RQ；
6. 连接文献并记录文献如何改变 Idea；
7. 重新检查假设、修改内容并建立新版本；
8. 保留旧版本并能够比较或恢复；
9. 生成只包含用户确认内容的阶段性 PDF；
10. 选择反馈、暂停、归档或主动进入正式研究项目；
11. 在任何阶段退出，而不被系统判定为失败；
12. 回到之前的 Idea、RQ、文献、PDF 和反馈继续工作。
