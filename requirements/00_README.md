## 当前最重要的三个问题

1. 首发到底解决早期科研者的哪一个最痛的资源问题：学习、找机会、研究设计、方法执行，还是获得反馈？
2. 首发用户是“做了多年 RA 的研究执行者”，还是“没有 RA 机会但想进入科研的人”？
3. P-layer 与 i-layer 的关系，是同一套学术民主化工具中的两个入口，还是先从一个最小工具开始？
