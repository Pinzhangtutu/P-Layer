# P-layer 产品架构（v0.2）

## 1. 信息架构

```text
P-layer
├── Research Workspace / 研究工作台
│   ├── 想法诊断
│   ├── 文献比较
│   └── 项目路径
├── Resource Library / 学术资源库
│   ├── 方法与模板
│   ├── 范例与解释
│   └── 机会与反馈
├── My Research / 我的研究
│   ├── 问题与假设
│   ├── 修改历史
│   └── 可展示的研究轨迹
└── P Note / 寄语入口
    ├── 给 PINZHANG 的一句话
    └── 收藏与个人联想
```

## 2. 最小用户流程

```text
进入 P-layer
  ↓
提出或输入一个研究想法
  ↓
获得结构化拆解与相关资源
  ↓
比较文献并识别缺口/不确定性
  ↓
形成下一步研究任务
  ↓
保存为个人研究轨迹并获得反馈
```

## 3. 寄语数据结构（建议）

| 字段 | 说明 | 首发是否必须 |
|---|---|---|
| id | 唯一标识 | 是 |
| text | 寄语正文 | 是 |
| author | 作者/来源人物 | 是 |
| source_status | 原文确认、可靠译文、思想启发/转述等 | 是 |
| source_url | 可追溯链接或书目信息 | 建议 |
| topic | 主题 | 是 |
| language | 原文/展示语言 | 建议 |
| editorial_note | 编者说明 | 否 |
| active | 是否进入当前内容池 | 是 |

## 4. 内容机制

- 内容池按主题、语气和使用场景组织，而不是只有作者分类。
- 每条内容必须经过来源状态标注。
- 随机浏览使用 session 级去重。
- 记录最近展示的内容，避免刷新后立即重复。
- 未经确认的内容不使用引号或“某人曾说”式确定性表达。

## 5. 身份机制

### Demo

- 标题：给 PINZHANG 的一句话 / A NOTE FOR PINZHANG。
- 署名或称呼可以直接使用 PINZHANG。

### 注册/登录后

- 标题使用当前用户昵称。
- 署名区域使用当前用户身份。
- 不把 Demo 用户名写死在产品逻辑中。

## 6. 与 i-layer 的暂定关系

目前建议把 P-layer 与 i-layer 视为同一产品生态中的平行入口：

- P-layer：更大的学术民主化产品层，负责资源接近、研究训练、机会路径与能力积累。
- i-layer：P-layer 内部的研究问题与证据工作流，负责文献比较、假设修订与证据管理。

是否共用账户、记忆、时间线和推荐系统，留到用户价值验证后决定。
