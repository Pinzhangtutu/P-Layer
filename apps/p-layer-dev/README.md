# Research P-layer · 社会科学研究工作台

这是一个本地运行的研究工作台。当前版本已经接入 R 统计引擎。

## Pia! 项目资料库（RAG）

设置页可以按项目导入 PDF、DOCX、TXT、Markdown、CSV、JSON 与 HTML。P-layer 在本机提取文字、分段并建立可检索索引；Pia! 回答前会检索当前项目的资料，并以 `R1`、`R2` 标记实际使用的来源。不同项目的资料不会混用。

- 普通本地模式不会上传文件或检索片段。
- 连接外部模型 API 时，只发送本次问题检索出的少量片段，不发送完整资料库。
- 扫描版 PDF 可在“设置 → PDF 可读化（OCR）”中直接生成可搜索副本。默认识别英文，也可选择英文 + 简体中文或英文 + 简体中文 + 繁体中文；原始 PDF 不会被覆盖。
- Pia! 本地模式通过 Ollama 调用 `qwen2.5:7b-instruct`。设置页可以检查 Ollama、下载约 4.7GB 的模型并测试自然对话；本地模型不可用时，软件会明确提示，不再用固定模板代替 AI 回答。
- 删除资料会同时删除它在 P-layer 本地 RAG 库中的检索片段，不影响 Zotero 原文件。

桌面版包含 Pia! 本地科研教练：它使用离线、可审计的社会科学研究方法知识库。Pia! 从软件内置的知识库检索，不会上传问题或项目数据；用户仍可选择用自己的 API Key 连接外部模型。

## Zotero 本地联动

P-layer 可以通过 Zotero Local API 只读连接本机文献库。在 Zotero 中打开“设置 → 高级”，启用“允许此计算机上的其他应用与 Zotero 通信”，然后在 P-layer 的“设置 → Zotero 文献库”中选择 Collection 并同步。

- Zotero 继续负责文献、PDF、笔记与批注；P-layer 不移动或复制 PDF。
- 每个 P-layer 项目分别绑定自己的 Zotero Collections，不跨项目混用。
- 默认索引元数据、摘要、标签与笔记；PDF 全文索引由用户主动选择。
- 头脑风暴可以按 Idea 检索绑定文献、查看 DOI/Zotero 来源并加入项目参考。
- Pia 会从绑定 Collection 检索材料并保留来源；这是本地 RAG，不会修改模型权重，也不会把 PDF 上传到外部服务。
- 当前版本保持只读，不会向 Zotero 写入标签、Collection 或笔记。

项目管理采用 `Project → Idea → Study → Data version` 四层结构。一个 Idea 可以建立多次独立 Study；每次 Study 分别保存设计、样本、预注册、研究步骤记录、原始/冻结/清理数据、分析代码、统计输出、效应量、置信区间、偏离记录和假设结论。跨 Study 证据总览不会只统计显著次数，并可在效应指标一致且信息充分时生成内部固定效应汇总。

右下角的“？”是独立的页面帮助小助手。它会说明当前页面的用途、推荐操作顺序和常见错误，并能检查 Pia 的本机连接；帮助内容不依赖 AI 服务。

DMG 不内置 R。需要统计分析时，请从 https://cran.r-project.org/bin/macosx/ 安装 R，并重新打开 P-layer。没有 R 时，项目管理、研究流程和 Pia 仍可正常使用。

## 启动

在 Finder 中双击：

```text
start.command
```

然后打开 http://127.0.0.1:8765/index.html。

也可以在此目录运行：

```bash
./start.command
```

不要再使用普通的 `python3 -m http.server` 启动，否则网页可以显示，但 R 上传分析接口不会工作。

当前功能按研究生命周期分为 9 步：

1. 研究问题
2. 理论与研究假设
3. 变量定义与操作化（IV、DV、中介、调节）
4. 研究设计与 power analysis 预留
5. 预注册、伦理与数据收集计划
6. 平台招募与问卷执行
7. 数据冻结、清理与质量审计
8. 统计分析与结果解释
9. 回到假设（支持、部分支持、未获得支持、证据不足）

每一步都配有 P-layer 白话解释，说明需要关注什么、数据代表什么，以及哪些结论不能过度说。

新增功能：文献参照导航。研究者可以点击示例研究，直接进入 DOI 或期刊正式页面，比较真实研究如何提出问题、操纵变量、分组、验证机制和报告结果。

## 当前主要能力（MVP 0.6）

- 每个项目可拆分为多个步骤和多个 Milestone
- 默认提供 Milestone 1、2、3 及各自 deadline
- 可编辑甘特图：步骤、所属 Milestone、开始、结束和完成度
- 头脑风暴按研究问题、理论机制、方法设计、测量变量、风险解释和待整理分类
- 每个页面底部都有 Research Copilot 长条对话框
- 头脑风暴采用可编辑数据库表格：一行一个想法，支持多个主题标签、时间、地点、案例、成熟度等级和研究类型
- 设置页可选择 OpenAI、Anthropic Claude、Google Gemini、DeepSeek、OpenRouter 或自定义 OpenAI-compatible API
- API Key 只保存在当前浏览器会话；供应商、模型和 Endpoint 保存在本机设置中，未配置密钥时自动回退到本地研究助手
- 主页底部提供独立的五幕动态产品演示，不会直接进入或修改正式研究流程
- 第8步提供交互统计阅读器：点击 p、F、t、效应量、置信区间、均值、SD、样本量等结果，右侧显示正式解释、误读边界和可展开的生活类比
- 当前 Copilot 使用可审计的本地结构化引擎，能立即产出页面相关草稿；云端模型接口已预留但未配置密钥
- 向下箭头只在页面下方确实还有内容时显示，到达底部后自动隐藏

## R 统计能力

- 读取 SPSS `.sav`、CSV 和 Excel `.xlsx`
- 识别并允许重新选择分组变量与数值结果变量
- 报告每组 n、均值、标准差、标准误和均值 95% 置信区间
- 描述统计与缺失概览
- Cronbach's alpha、项目总分相关和删除题项后的 alpha
- 两组 Welch 独立样本 t 检验与 Hedges' g
- 三组及以上单因素 ANOVA 与 eta squared
- 操纵检查
- 多元线性回归与系数置信区间
- 两因素实验 / 2×2 ANOVA、交互效应、partial eta squared 与 cell 统计
- Bootstrap 简单中介分析（a、b、c、c-prime 和间接效应区间）
- 调节回归、交互项与简单斜率
- 两水平配对 t 检验及多水平重复测量分析
- 输出接近 APA 格式的结果句和初学者解释
- 缺失值采用完整案例分析并明确报告未进入分析的行数
- 上传文件仅在本机临时处理，分析完成后删除临时副本
- 每次成功分析自动归档到当前项目，最多保留最近 20 次结果

第八步附带 `sample_experiment.csv`，可以点击“用示例数据测试 R”验证链路。

当前边界：复杂协变量中介、多分类 X 的中介、调节中介、混合效应模型、缺失数据插补、稳健标准误、贝叶斯分析和多重比较校正尚未加入。正式发表前仍应由研究者检查模型假设、数据结构、预注册和研究设计。
